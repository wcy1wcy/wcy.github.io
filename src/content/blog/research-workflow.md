> 这是一篇**示例文章**，用来展示长文的排版效果。换成你自己的内容后删掉即可。

工具换了很多轮，最后留下来的都是“足够简单、每天都会用”的那些。下面按一篇论文的生命周期来写。

## 读

- 每天早上花二十分钟扫一遍新论文，只看标题和摘要。
- 感兴趣的先存进文献管理软件，打一个 `to-read` 标签。
- 真正要精读的，每周不超过三篇。精读时在旁边写一段“这篇改变了我什么想法”。

## 写代码

实验代码和论文代码分开放。实验代码可以乱，论文代码必须能一键复现。

```python
# 每个实验开头固定写这几行，省去很多“当时用的什么参数”的烦恼
import json, time, pathlib

run = pathlib.Path("runs") / time.strftime("%Y%m%d-%H%M%S")
run.mkdir(parents=True)
(run / "config.json").write_text(json.dumps(config, indent=2))
```

## 整理文献

投稿前最头疼的是参考文献：同一篇论文被导入了三次，大小写不统一，年份缺失。为此我写了一个很小的脚本 [bibtidy](/code/bibtidy/)，去重、排序、补齐格式，一行命令搞定。

## 记下每天做了什么

每天收工前花两分钟，写三行：今天做了什么、卡在哪里、明天第一件事做什么。第二天坐下来就不用再“热身”半小时。我用的是一个叫 [pensieve](/code/pensieve/) 的小命令，把想法从脑子里抽出来，存进一个文本文件。

| 阶段 | 工具 | 频率 |
|---|---|---|
| 读 | 文献管理软件 + 标签 | 每天 |
| 写代码 | Git + 固定的实验模板 | 每天 |
| 整理文献 | bibtidy | 投稿前 |
| 记录 | pensieve | 每天收工前 |

工具只是工具。最重要的习惯其实只有一个：**每天都做一点**。
